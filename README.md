# Trabalho-Timestamp

Este trabalho é uma api em Node.js, com funcionalidades de um Timestamp, mostrando a data atual, convertendo datas
de Unix para UTC e vice-versa, além de calcular a diferença entre datas. Utilize a interface na web para interagir 
com o trabalho.

## **Pré-requisitos**

Antes de começar, certifique-se de ter os seguintes itens instalados no seu computador:

- [Node.js](versão 14 ou superior)
- [npm](gerenciador de pacotes do Node.js)

## **Passo a passo para executar o projeto**

1. **Clone o repositório**
   
   Faça o clone do repositório em sua máquina local:
   ```bash
   git clone https://github.com/Vitor9373/Trabalho-TImestamp.git
   ```

2. **Acesse o diretório do projeto**
   
   Entre no diretório onde o projeto foi clonado:
   ```bash
   cd Trabalho-TImestamp
   ```

3. **Instale as dependências**
   
   Instale todas as dependências necessárias listadas no arquivo `package.json`:
   ```bash
   npm install
   ```

4. **Inicie o servidor**
   
   Inicie o servidor Node.js com o comando:
   ```bash
   npm start
   ```
   O servidor será iniciado e estará disponível em `http://localhost:3000`.

5. **Acesse a aplicação**
   
   Abra um navegador da web e acesse:
   ```
   http://localhost:3000
   ```

6. **Utilize as funcionalidades**
   
   - **Data atual**: Exibe a data atual nos formatos Unix e UTC.
   - **Conversor de datas**: Converte uma data fornecida pelo usuário para os formatos Unix e UTC.
   - **Diferença entre datas**: Calcula a diferença entre duas datas fornecidas pelo usuário.
